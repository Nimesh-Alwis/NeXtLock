# NEXTLOCK Requirements

## Project Overview

NEXTLOCK is a simple password manager application.

Users can organize accounts into categories and manage usernames and passwords through a modern user interface.

---

## Main Features

### Category Management

- View categories
- Add categories
- Delete categories
- Rename categories

Examples:

- Gmail
- Facebook
- Snapchat

---

### Account Management

- Add account
- Edit account
- Delete account

---

### Password Management

- Save password
- Update password
- Track update date and time

---

### Data Storage

- Store data in Markdown (.md) files
- One file per category

---

### User Interface

- Modern design
- Easy navigation
- Responsive layout

---

## Future Features

- Search accounts
- Password generator
- Encryption
- Dark mode
- Export and import data
