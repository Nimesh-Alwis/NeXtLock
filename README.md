# 🔐 NeXtLock - Multi-Profile Password Vault

A modern, secure, and offline **Password & Credential Vault** built with HTML, CSS, and Vanilla JavaScript. Features a dark glassmorphic UI, multi-user profiles, double-locked hidden vault, and secure multi-format exports.

---

## ✨ Features

- **👤 Multi-User Profiles**: Partitioned password vaults per user profile with custom photo avatar upload.
- **🕵️ Double-Locked Hidden Vault**: Built-in secret category requiring Master Password re-verification.
- **🔑 Account & Credential Management**: Save passwords, custom photos, auto brand icons, and secret recovery notes.
- **⚡ Password Generator**: Built-in strong random password generator with live strength meter.
- **📤 Multi-Format Export**: Securely export vault credentials into `.md`, `.csv`, `.txt`, or `.json` files after password verification.

---

## 🚀 How to Run

Simply open `index.html` or `src/login/login.html` in any web browser!

```bash
# Or serve locally via Node / Live Server:
npx serve .
```

---

## 📂 Technology Stack

- **Frontend**: HTML5, Vanilla CSS3 (Dark Glassmorphism), JavaScript (ES6+)
- **Storage**: LocalStorage (Per-profile isolated client-side storage)
